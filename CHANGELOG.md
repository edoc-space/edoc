# История версий

## 2.0.0 — 2026-09-29

### Требования и совместимость

- Минимальная версия PHP повышена с 8.4 до 8.5.
- Зависимости `phpsoftbox/*` переведены с `dev-master` на стабильную ветку
  `^1`; обновлён `composer.lock`, удалён `minimum-stability: dev`.
- `phpsoftbox/cs-fixer` требует `^1.2.2`.
- Загрузка конфигурации использует обязательный `ConfigFactory::baseDir`
  и аргумент `environment`. CLI получает окружение приложения.
- Канонические ссылки учитывают `X-Forwarded-*` только от доверенных прокси.
  Настройка `APP_TRUSTED_PROXIES` применяется через `TrustedProxyMiddleware`
  в начале обработки запроса.

### Переход с 1.x

1. Подготовьте PHP 8.5, установите зависимости по `composer.lock` и соберите
   фронтенд. Пользовательский контент и плагины остаются в `local/`.
2. Для работы за обратным прокси задайте `APP_TRUSTED_PROXIES` фактическими
   IP/CIDR. Не используйте весь Интернет как доверенный диапазон.
   В Nginx передавайте исходные `HTTPS` и `REQUEST_SCHEME`; уберите прежние
   `map`, которые подменяли их по `X-Forwarded-Proto` до проверки доверия.
3. Очистите прежние кеши окружения, конфигурации, маршрутов и
   скомпилированного контейнера, затем перезапустите PHP-процессы.
   Для DI доступен `ContainerBuilder::clearCompiledCache()` с каталогом
   `Path::cachePath('di')`. Контент и плагины при очистке кешей не затрагиваются.
4. Если установка использует шифрование, новые операции требуют ключа
   не короче 32 байт. Не заменяйте рабочий ключ без сохранения возможности
   прочитать прежние данные. Старые зашифрованные cookie требуют повторного входа.

### Проверки

47 PHP-тестов, 259 проверок; `composer cs:check`, `composer validate`,
`yarn tsc --noEmit`, `yarn build`, `APP_ENV=test php psb container:validate`
(64 определения) и `APP_ENV=test php psb app:health` прошли.
Сценарии канонических ссылок покрывают доверенный прокси и прямой запрос
с поддельными заголовками.
